## Version longue (850 caractères - Engagement Max)

```
🚴 Color_communes v2 — Bot Telegram pour cartographier mes sorties cyclistes

Après 11h de dev (Phase 1-8), mon bot Telegram transforme mes traces GPX Strava 
en cartes colorisées des communes françaises visitées. Lancé en production sur mon 
NAS Synology 🎯

✨ Ce qu'il peut faire:
• /history [date] — Communes visitées depuis une date donnée
• /compare [date] — Avant/après split-screen pour analyser la croissance
• /settings — 4 palettes couleurs + 3 tailles de carte (customisation utilisateur)
• /gpx_list — Audit complet des 50+ fichiers GPX importés
• /cumul — Carte cumulative de tous les territoires (1800+ communes, 80+ depts)
• /stats — Statistiques globales + top communes

🛠️ Stack technique:
→ Telegram Bot API v20
→ GPX parsing + haversine distance sampling (500m intervals)
→ Nominatim reverse geocoding + rate limiting
→ Geopandas + matplotlib pour les cartes PNG
→ SQLite cumulative avec détection doublons (hash MD5)
→ Docker Synology en production

📊 Stats du projet:
• 1232 sorties historiques (2012-2026)
• 1800+ communes visitées
• 80+ départements couverts
• Zéro retraitement des fichiers (déduplication par hash)

Prochaine: Phase 9 — Import historique Strava complet + comparaisons année/année

Curieux de savoir comment c'est construit? Le code reste privé, mais je documais 
tout dans mon wiki Obsidian personnel 📚

#Python #Telegram #OpenStreetMap #Docker #PersonalProject #CycloCommunities 
#GIS #Homelab
```
