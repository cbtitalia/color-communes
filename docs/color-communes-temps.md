## Comment remplir

Quand tu travailles sur une phase, note :
- La **date** de la session
- Le **temps réel** passé (ex: `2h30`)
- L'**écart** = réel − estimé (ex: `+1h00` si plus long, `-0h30` si plus rapide)

Tu peux avoir plusieurs lignes pour la même phase si le travail est étalé sur plusieurs sessions.
